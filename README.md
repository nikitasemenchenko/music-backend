# Music Streaming Service - Backend

Бэкенд-сервис для музыкального стримингового приложения на Ktor и PostgreSQL. Обеспечивает отдачу метаданных каталога и потоковую передачу аудиофайлов с поддержкой `HTTP Range Requests`.

---

## Технологический стек

* **Язык:** Kotlin 
* **Фреймворк:** Ktor
* **База данных:** PostgreSQL
* **ORM:** Exposed ORM + HikariCP
* **Инфраструктура:** Docker, Docker Compose

---

## Эндпоинты API

| Метод | Путь | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/v1/tracks` | Получить полный каталог треков |
| `GET` | `/api/v1/tracks/{id}` | Получить подробную информацию о треке |
| `GET` | `/api/v1/tracks/{id}/stream` | Потоковое вещание аудиофайла (`Range: bytes=...`) |

Также есть админские эндпоинты.
